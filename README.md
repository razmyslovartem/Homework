## Проект: Домашняя работа (Homework)
### Проект предоставляет функции для фильтрации и сортировки банковских операций.
### Инструкции по установке и использованию разработанных функций
### Установка:

1. Клонируйте репозиторий:
```
git clone git@github.com:razmyslovartem/Homework.git
```
2. Установка зависимостей

Проект использует следующие зависимости:

* Основные: Python 3.8+

* Для разработки и тестирования: Poetry (менеджер зависимостей)

Все зависимости указаны в файле `pyproject.toml`:

Основные зависимости перечислены в секции `[tool.poetry.dependencies]`

Линтеры flake8, mypy, black и isort содержатся в группе lint - в секции `[dependency-groups] lint`

Установите Poetry:
```
pip install poetry
```
Установите зависимости проекта:
```
poetry install
```
### Конфигурация
Настройка окружения

Убедитесь, что Python 3.8+ установлен:
```
python --version
```
Проверьте установку Poetry:
```
poetry --version
```
При необходимости обновите Poetry:
```
poetry self update
```

- В модуле `generators` функция `filter_by_currency` принимает на вход список словарей, представляющих транзакции и возвращает итератор, который поочередно выдает транзакции, где валюта операции соответствует заданной (например, USD).

### Тестирование

Проект использует библиотеку pytest для тестирования. Все основные модули проекта покрыты тестами, что позволяет обеспечивать стабильность и надежность кода. Тесты находятся в папке tests, и их можно запустить командой:

```
pytest --cov=src --cov-report=html
```

### В тестах использованы фикстуры и параметризация.

		• Покрытие тестами составляет более 80%. (Функциональный код покрыт тестами более чем на 80%.)
		• Основные модули, такие как masks, processing, и widget, имеют высокий уровень покрытия, подтверждающий корректность их работы.
		• Отчет о покрытии можно найти в папке htmlcov, открыв файл index.html в браузере.
		• Тесты включают проверку всех критических функций.
		• Используются параметризированные тесты и фикстуры для различных сценариев.

### Тесты функции `get_mask_card_number`:
- Тестирование правильности маскирования номера карты.
- Проверка работы функции на различных входных форматах номеров карт, включая граничные случаи и нестандартные длины номеров.
- Проверка, что функция корректно обрабатывает входные строки, где отсутствует номер карты.

### Тесты функции `get_mask_account`:
- Тестирование правильности маскирования номера счета.
- Проверка работы функции с различными форматами и длинами номеров счетов.
- Проверка, что функция корректно обрабатывает входные данные, где номер счета меньше ожидаемой длины.

### Тесты функции `filter_by_currency`
- Проверка, что функция корректно фильтрует транзакции по заданной валюте.
- Проверка, что функция правильно обрабатывает случаи, когда транзакции в заданной валюте отсутствуют.
- Проверка, что генератор не завершается ошибкой при обработке пустого списка или списка без соответствующих валютных операций.

### Тесты функции `transaction_descriptions`
- Проверка, что функция возвращает корректные описания для каждой транзакции.
- Проверка работы функции с различным количеством входных транзакций, включая пустой список.

### Тесты функции `card_number_generator`
- Проверка, что генератор выдает правильные номера карт в заданном диапазоне.
- Проверка корректности форматирования номеров карт.
- Проверка, что генератор корректно обрабатывает крайние значения диапазона и правильно завершает генерацию.
